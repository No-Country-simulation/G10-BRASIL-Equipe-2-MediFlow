## 🏥 MediFlow – Agente Autônomo para Triagem, Extração e Roteamento de Documentos Clínicos

### Descrição do projeto
Desenvolver um agente inteligente e autônomo capaz de receber documentos clínicos e administrativos em múltiplos formatos (arquivos PDF digitalizados, imagens de exames/receitas ou textos), classificá-los automaticamente, extrair entidades e dados clínicos essenciais com altíssima precisão e roteá-los para o destino correto sem necessidade de intervenção humana manual para casos padrão.
